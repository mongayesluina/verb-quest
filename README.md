# Verb Quest – Present & Past

Educational web app for classroom practice with **200 common English verbs**.

## Learning focus

Verb Quest now teaches verbs as part of complete grammar, not only as isolated past forms:

- Base form
- Present simple with I / you / we / they
- Present simple with he / she / it
- Past simple
- Past participle
- Spanish meaning
- Present and past example sentences
- Affirmative, negative and interrogative structures
- Correct use of **do / does / did**
- Special treatment of **BE: am / is / are / was / were**
- Sentence order and tense transformation

## Activities

The interface is organized into three learning stages.

### Learn
- Verb Explorer
- Present or Past?
- Fill the Sentence

### Build
- Build the Sentence
- Change the Tense
- Grammar Lab

### Challenge
- Memory Pro
- Save the Robot — only 2 mistakes allowed
- Match Rush
- Verb Ladder
- Speed Run
- Final Challenge

## Classroom tools

- 200 verbs: regular and irregular
- 3 difficulty levels + All 200 mode
- Teacher Mode for custom verb sets
- XP and streak tracking with localStorage
- English speech synthesis
- Responsive layout for desktop, tablets and phones

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages

The current application entry point is `index.html`. Grammar logic is isolated in `v3-grammar.js`, application state/navigation in `v3-core.js`, activities in `v3-games.js`, and the additional grammar interface styles in `v3.css`.
